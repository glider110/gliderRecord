🎵 悬浮音频播放器

这是一个悬浮式的音频播放器，会固定在页面右下角，不影响页面浏览。 播放器会自动加载音频列表，支持播放控制、进度调节、音量控制等功能。

✨ 主要特性

  • 🎵 悬浮设计 - 固定在页面右下角，不影响内容浏览
  • ▶️ 完整控制 - 播放、暂停、上一首、下一首
  • 📊 进度条 - 点击进度条快速跳转，实时显示播放时间
  • 🔊 音量控制 - 滑动调节音量大小
  • 🔁 播放模式 - 列表循环、单曲循环、随机播放、顺序播放
  • 📋 播放列表 - 显示所有歌曲，点击切换播放
  • 💡 最小化功能 - 最小化后只显示小图标，节省空间
  • 🎨 美观界面 - 渐变色设计，旋转动画效果
  • 📱 响应式 - 完美适配移动设备

📝 使用说明

  • 播放器会自动显示在页面右下角
  • 点击播放列表中的歌曲可以切换播放
  • 点击进度条可以快速跳转到指定位置
  • 点击音量按钮可以显示/隐藏音量控制
  • 点击播放模式按钮可以切换不同的播放模式
  • 点击最小化按钮可以收起播放器，节省空间
  • 点击关闭按钮可以隐藏播放器

🔧 集成到你的页面

在任何页面中添加以下代码即可使用：

<!-- 引入样式 -->
<link rel="stylesheet" href="floating-audio-player.css">

<!-- 引入脚本 -->
<script src="floating-audio-player.js"></script>

<!-- 初始化播放器 -->
<script>
  const player = new FloatingAudioPlayer({
    playlist: [
      {
        title: '理想三旬',
        artist: '陈鸿宇',
        src: 'resource_docs/audio/理想三旬 - 陈鸿宇.mp3'
      },
      {
        title: '走歌人',
        artist: '暗杠',
        src: 'resource_docs/audio/走歌人 - 暗杠.mp3'
      }
    ]
  });
</script>
