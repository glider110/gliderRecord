§ Git 工作流速查

§ 基础状态查看

git log / git reflog              # 提交历史
git diff                          # 未提交修改（详细）
git status                        # 未提交修改（简洁）
git branch -a                     # 所有本地+远程分支
git remote -v                     # 查看远程地址
git config --global --list        # 全局配置（system/global/local 三级）

§ 版本回退

git reset --hard HEAD^            # 回退到上个版本
git reset --hard HEAD~3           # 回退3次提交
git reset --hard <commit_id>      # 回退到指定commit
git checkout <commit> -b <branch> # 从历史commit创建新分支
git commit --amend -m "新信息"     # 修改最后一次commit信息（仅限最后一次）

§ stash：临时保存（切换场景）

git stash save "描述"    # 临时储藏工作区
git stash list           # 查看储藏列表
git stash show -p        # 查看差异
git stash pop            # 恢复并删除最新储藏
git stash apply          # 恢复但保留储藏
git stash drop/clear     # 删除/清空

适用场景：代码写到一半，临时需要切换分支但还达不到一次commit要求。

§ worktree：同时操作多个分支

git worktree list

# 创建独立工作目录处理紧急bug
git worktree add ../hotfix-work -b hotfix/urgent-fix
cd ../hotfix-work
# 修复、提交、推送...
git push origin hotfix/urgent-fix

# 回主目录继续开发
cd ../main

# 清理（hotfix合并后）
git worktree remove ../hotfix-work
git branch -d hotfix/urgent-fix

适用场景：需要同时操作两个分支（如主线开发同时处理hotfix），避免stash+切换的繁琐。

§ git restore：恢复文件

git restore <file>                   # 丢弃工作区修改
git restore --staged <file>          # 取消暂存
git restore --source=<commit> <file> # 从历史commit恢复指定文件
git restore .                        # 恢复所有
git restore '*.cpp'                  # 批量恢复（按模式）
git restore -p <file>                # 交互式选择

§ 远程与分支操作

# 删除远程分支
git push origin --delete <branch>
git remote update origin --prune    # 同步本地远程分支列表

# 切换到远程分支
git checkout -b develop origin/develop

# fetch+对比（不merge）
git fetch origin master:tmp
git diff tmp
git merge tmp
git branch -d tmp

# 双远程
git remote add backup https://xxx.git
git push backup main
git push backup --all

§ submodule：管理子模块

# 初始化（克隆含子模块的仓库时）
git submodule update --init --recursive

# 查看状态
git submodule status

# 更新所有子模块到远端最新
git submodule update --remote

# 更新指定子模块
git submodule update --remote <path>

# 提交主仓库的指针变化
git add <path> && git commit -m "update submodule"

# 添加子模块
git submodule add <repo-url> <path>

§ Commit 规范

前缀 含义
feat 新功能
fix Bug修复
refactor 代码重构（无新功能/bugfix）
perf 性能优化
docs 文档变更
style 格式调整（不影响逻辑）
test 测试用例
chore 构建流程/依赖变更
revert 回滚

§ SSH 免密登录

# 免密代码库
ssh-keygen -t rsa -C "your@email.com"
cat ~/.ssh/id_rsa.pub  # 复制到 GitLab/GitHub

# 免密 SSH 到指定服务器
ssh-keygen -t rsa -b 4096
ssh-copy-id user@<server-ip>

优先用 SSH 而非 HTTPS，避免频繁输密码。

§ 合并多次 commit 为一次

git reset --soft <target_commit_id>   # 把多次commit内容回到暂存区
# 切换到目标分支
git commit -m "合并的提交信息"

用于：把分支A的几次提交整合为一次，cherry-pick到分支B。
