## 🔧 使用说明

### 阅读PDF文档

1. **点击卡片** - 点击任意PDF卡片，在新标签页中打开阅读器
2. **在线阅读** - 使用 PDF.js 在浏览器中直接阅读
3. **翻页控制** - 使用上一页/下一页按钮，或键盘方向键
4. **缩放** - 使用放大/缩小按钮，或键盘 +/- 键
5. **全屏** - 点击全屏按钮进入全屏阅读模式

### 快捷键

- `←` / `→` - 上一页/下一页
- `+` / `-` - 放大/缩小
- `F` - 全屏切换
