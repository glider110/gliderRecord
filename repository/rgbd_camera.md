## 4. Stereolabs

### 4.1 ZED Mini

| 项目 | 参数 |
| --- | --- |
| **深度技术** | 被动双目立体视觉（无投射器） |
| **深度分辨率** | 最高 4416×1242（双目原始），深度图 1920×1080 |
| **RGB 分辨率** | 2×2208×1242 @ 15fps / 2×1920×1080 @ 30fps / 2×1280×720 @ 60fps |
| **深度范围** | 0.1 ~ 12m（短基线优化近距） |
| **深度精度** | ≤1% @ 1m |
| **视场角** | H 90° × V 60°（110° 对角线） |
| **基线** | 63mm |
| **IMU** | 内置 6 轴 IMU（加速度计 + 陀螺仪） |
| **接口** | USB 3.0 Type-C |
| **尺寸** | 124.5 × 30.5 × 26.5 mm |
| **重量** | 62.9g |
| **功耗** | ≤5W |
| **SDK** | ZED SDK / ROS/ROS2 / CUDA 加速 / Python API |
| **典型应用** | VR/AR 混合现实、机器人 SLAM、无人机视觉、自动驾驶 |

**特点：**
- **被动双目**：无 IR 投射器，不受结构光/ToF 多机干扰，室外强光下同样可用
- **高帧率**：720p 下可达 60fps，适合高速运动场景
- **内置 IMU**：原生支持 VIO（视觉惯性里程计），SLAM 精度高
- **CUDA 加速**：ZED SDK 深度依赖 NVIDIA GPU，深度计算、目标检测、空间建图均 GPU 加速
- **紧凑设计**：63mm 短基线 + 轻量机身（63g），专为头戴式 VR/AR 和小型机器人设计
- **丰富的感知功能**：SDK 内置目标检测、骨骼追踪、空间建图、位姿追踪等

**注意事项：**
- **必须配合 NVIDIA GPU 使用**（Jetson 系列或桌面级显卡），不支持纯 CPU 运行
- 被动双目在弱纹理/暗光场景下深度质量下降
- 相比 ZED 2/2i，ZED Mini 无温度/气压传感器

**ZED 系列对比：**

| 型号 | 基线 | 最大深度 | 传感器 | 防护 | 定位 |
| --- | --- | --- | --- | --- | --- |
| ZED Mini | 63mm | 12m | IMU | 无 | VR/AR、近距机器人 |
| ZED 2 | 120mm | 20m | IMU + 气压 + 温度 + 磁力计 | 无 | 通用机器人/无人机 |
| ZED 2i | 120mm | 20m | IMU + 气压 + 温度 + 磁力计 | IP66 | 工业/室外 |
| ZED X Mini | 50mm | 10m | IMU | IP67 | 嵌入式、Jetson 原生 |

## 6. 技术路线对比

| 技术 | 代表产品 | 优势 | 劣势 |
| --- | --- | --- | --- |
| **结构光** | DW2 | 近距精度高、成本低 | 室外/强光下退化、多机干扰 |
| **主动双目** | Gemini 335L、D435 | 室内外通用、远距可用 | 弱纹理区域精度下降 |
| **被动双目** | ZED Mini | 无投射器干扰、室外强光可用、高帧率 | 弱纹理/暗光退化、依赖 GPU |
| **iToF** | OKA | 体积小、精度稳定 | 多路径反射干扰、距离有限 |
| **dToF** | NYX650 | 精度高且一致、抗环境光 | 分辨率相对较低、成本较高 |

---

## 7. 选型建议

- **扫地机器人 / 低成本避障**：DW2（结构光，成本低、近距好）
- **机器人 SLAM / 导航**：Gemini 335L（宽 FOV、国产替代 D435）或 D435i（IMU 加持、生态成熟）
- **机械臂末端抓取**：D405（超近距、亚毫米精度）
- **AGV 通用避障**：NYX650（dToF 抗光照、精度一致）或 OKA（iToF 小体积）
- **需要 IMU 的 VIO 场景**：D435i、Gemini 335Lg 或 ZED Mini
- **VR/AR / 高帧率视觉**：ZED Mini（被动双目 + IMU，60fps，轻量）
- **室外强光 + NVIDIA 平台**：ZED Mini / ZED 2i（被动双目不受日光干扰）
