# 机器人数据采集项目

围绕机器人感知研发建立数据采集、传感器记录和离线分析素材，为避障、定位和目标识别提供可回放的数据基础。

## 主要工作

- 采集机器人相机、雷达和现场环境数据，保留传感器时序信息。
- 结合录包和离线回放复现现场问题，辅助算法调试和效果验证。
- 将采集结果用于模型、区域和感知策略的持续优化。
